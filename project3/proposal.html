Project 3 Proposal

Concept

Project 3 will be a simple desktop web bullet hell game, inspired by games like asteroids and astro prospector. The player will only be able to interact with the game with the mouse, and are centered in the screen at all times. By left clicking, the player can shoot bullets at approaching enemies.

Story

The story would be rather simple, something like "Attack these enemies and protect your home!"

Art

At this moment, I imagine having simple art, such as using ASCII characters, would be my current goal.
